# Pork & Garlic Ice Cream — Year 2 Winter Decision Tool

This is a self-contained calculator for the Managerial Accounting home assignment. Open `index.html` in a browser to use it. Entries and recommendation notes are saved only in that browser on that device.

## Year 1 validation example

The supplied Winter case is already filled in. It should calculate:

- Net profit: **Sh4,171**
- Closing cash: **Sh73,546**

## Publish with GitHub and Vercel

1. Create a new GitHub repository, for example `pork-garlic-winter-tool`.
2. Upload the three website files: `index.html`, `styles.css`, and `app.js` (including this README is recommended).
3. In Vercel, choose **Add New → Project**, select your GitHub repository, and click **Deploy**. No build settings are needed for this static website.
4. Test the live link by changing a value in Winter A and confirming its results and warnings update.
5. Enter only your own GitHub repository link and Vercel link in the cells assigned to you in the shared submission spreadsheet. Do not edit, sort, or change other students’ information.
